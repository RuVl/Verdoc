# Country оставлен под своим именем

При уходе от предметных терминов (`Passport` → `Product`, `PassportFile` → `StockItem`)
`Country` был кандидатом на переименование в `Category`: связь `Product.country` обязательная
(`null=False`, `on_delete=CASCADE`), то есть схема утверждает, что **любой** товар обязан
принадлежать стране.

Решено оставить `Country` как есть. Причины против переименования — флаг, завязанный на ISO-код,
и таблица переводов `modeltranslation` (`passport/translation.py`), которую переименование тоже
затрагивает.

## Consequences

- Линейка товаров, к которой страна неприменима, будет представлена записями `Country`
  с `code="-"` — код это уже умеет (`Country.flag` возвращает `"-"`). Админка при этом покажет
  «Страна: Премиум-пакеты».
- Если такая линейка действительно появится, переименование в `Category` — отдельная миграция:
  `RenameModel` + `RenameField` на `Product.country` + перенос строк `modeltranslation`.
  Дешевле сделать это тогда, чем платить за него сейчас без реальной потребности.
